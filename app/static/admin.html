To restore: stop the server, copy the chosen file over data/attendance.db, and start the server again. Backups hold every student's data, so keep copies somewhere safe.

Upload the student list

A CSV file (Excel: Save As → CSV UTF-8) with this header row:
student_no,name,class_id,uniform_body,club_society,sport_game
for example 13255,Vicky Tan,4E1,Gadet Police,Pancaragam Harmonica,Basketball.

  • Every student appears straight away, marked not registered yet. Students register once to get their QR.
  • Each co-curriculum is created the first time it appears, with these students as its members.
  • Uploading again (e.g. a new school year) updates names, class IDs and co-curricula. Accounts, QR codes and attendance stay. To correct a mistake, fix the spreadsheet and upload it again.

Upload the teacher list

Upload the student list first, so the co-curricula exist. Then a CSV file with this header row:
teacher_id,name,position,email,co_curricula
for example T001,Eren Yeager,Senior Assistant,eren@school.edu.my,Gadet Police; Basketball.

  • co_curricula: the co-curricula the teacher is in charge of, separated by ;. The names must match the student list exactly. This is the only way a teacher is put in charge, so teachers cannot pick the wrong ones.
  • email is optional: teachers give their own when they register. It is used for forgot password.
  • Teachers register once at with their teacher ID and name.
